Helm

Helm is a native macOS menu bar app that serves as a unified, safety-first control plane for your development environment. It brings over 15 package managers—including Homebrew, npm, pip, Cargo, mise, and rustup—under one roof.

Drawing from my cybersecurity and military background, Helm is built entirely on the premise of deterministic behavior. It never runs blind automated updates in the background. Instead, it provides total visibility into what is installed, what needs updating, and safely executes those changes only when you command it to.

It features a highly optimized Rust core for secure, rapid state execution, paired with a modern SwiftUI frontend for a flawless, native Mac user experience.

Guilty Party

Guilty Party is a proprietary platform designed to power live, hosted interactive storytelling experiences. It is the direct synthesis of my two professional lives: software architecture and theatrical performance.

Traditional live events often struggle to scale interactivity without losing the human element. Guilty Party bridges this gap by providing robust backend systems to track audience choices, manage narrative state, and coordinate actors, allowing the story to fluidly adapt to the audience in real-time.

Tilewright

Tilewright is an evidence-driven Rust toolkit engineered specifically for game developers. It provides robust mechanisms for understanding, validating, and safely transforming tile-based RPG project data.

Game data integrity is often a fragile pipeline. Tilewright applies strict validation rules and type-safe transformations, ensuring that external modifications to game assets and configuration files are safe, predictable, and structurally sound before they ever reach the game engine.
